# Credit Risk Prediction using Machine Learning

An end-to-end machine learning project that predicts credit risk using borrower and loan-related information.

## Features

- Exploratory Data Analysis
- Missing value handling
- Numerical feature scaling
- Categorical feature encoding
- Scikit-learn preprocessing pipelines
- Random Forest Classification
- Hyperparameter tuning using GridSearchCV
- Model evaluation using Accuracy, Precision, Recall, F1-Score, and ROC-AUC
- Confusion Matrix and Precision-Recall Curve
- Feature Importance Analysis
- Model saving using Joblib

## Technologies Used

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Joblib

## Machine Learning Workflow

Data Collection → Data Preprocessing → Feature Engineering → Train-Test Split → Model Training → Hyperparameter Tuning → Model Evaluation → Feature Importance → Model Saving

## Model

The project uses a Random Forest Classifier, with hyperparameters optimized using GridSearchCV and cross-validation.
